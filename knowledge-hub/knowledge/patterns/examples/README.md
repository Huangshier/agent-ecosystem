# Pattern Examples

Positive and negative fixtures for knowledge patterns in this directory's
parent (`../`). Each fixture demonstrates how a pattern applies (or does not
apply) to a concrete, fictional scenario.

## Verification Boundary

**Manual review only.** No automated validator is wired to these fixtures.
They serve as human-readable evidence that a pattern's steps produce a
coherent, auditable result when applied to a non-trivial input. Validators
may be added in the future; until then, fixture correctness is verified by
maintainer review.
