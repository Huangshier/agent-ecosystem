# Reusable Engineering Patterns

Patterns describe repeatable cross-project workflows. They are not failure
postmortems and they are not project-local plans.

## Retrieval Rule

- Do not preload every pattern.
- Start from `knowledge-hub/knowledge-catalog.md`.
- Open a pattern only when its use case matches the current work.

## Entry Format

Recommended fields:

- `Maturity: draft | verified | proven | deprecated`
- `Scope: cross-project | project-specific`
- `Source: manual | promoted`
- `Last reviewed: YYYY-MM-DD`
- Summary
- Use when
- Do not use when
- Steps
- Validation
