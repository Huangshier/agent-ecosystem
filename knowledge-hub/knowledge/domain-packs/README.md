# Domain Packs

Domain packs are optional public knowledge bundles for recurring technical
domains. They start as Markdown knowledge before becoming skills.

Use a domain pack when:
- the task needs domain vocabulary, common constraints, or recurring checks
- the knowledge is reusable across more than one project
- the content is public-safe and does not depend on a private environment

Do not turn a domain pack into a skill until repeated usage shows a stable,
scriptable workflow.

Lifecycle, manifest, promotion, public-safety, validation, and profile-boundary
rules are defined in
[Domain pack governance](../../../docs/domain-pack-governance.md).
