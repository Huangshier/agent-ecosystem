# Security Policy

## Reporting

Please report sensitive information exposure or security concerns privately
through the repository owner's preferred security contact once one is published.
Do not open a public issue containing secrets, private paths, or exploit details.

## Public Repository Rules

This repository should not contain:

- credentials, API keys, tokens, cookies, private keys, or account identifiers
- private repository URLs or migration mappings
- local machine paths or personal runtime paths
- sensitive audit notes
- private domain workflow details

## Release Audit

Before a public release or push intended for public use, run a sensitive
information audit over the full public tree and review false positives manually.
