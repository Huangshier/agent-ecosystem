# Cross-Project Standards

Standards capture stable rules that guide reusable agent ecosystem content.
They should be narrow, durable, and easy to apply across projects.

## Retrieval Rule

- Do not preload every standard.
- Start from `knowledge-hub/knowledge-catalog.md`.
- Open a standard when you need a boundary, rule, or durable project convention.

## Entry Format

Recommended fields:

- `Maturity: draft | verified | proven | deprecated`
- `Scope: cross-project | project-specific`
- `Source: manual | promoted`
- `Last reviewed: YYYY-MM-DD`
- Rule
- Applies to
- Does not apply to
- Checklist
