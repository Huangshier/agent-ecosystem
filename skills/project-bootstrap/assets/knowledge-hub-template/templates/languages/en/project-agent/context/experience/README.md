# Experience Context

Project memory language: English.

Store recurring pitfalls and proven fixes here.

## Entry Index

Use this optional human-maintained index when the directory grows beyond a few
entries.

| File | Summary | Keywords |
| --- | --- | --- |

Keep index columns limited to public-safe discovery metadata. Add `Maturity` or
`Reviewed` only when those values are manually maintained; do not include
runtime telemetry, usage counts, `last_accessed`, or automatic decay state.

Keep each entry concise:
1. Problem
2. Root Cause
3. Fix
4. Verification
5. Prevention rule
