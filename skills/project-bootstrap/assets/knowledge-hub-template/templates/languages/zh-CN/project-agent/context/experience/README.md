# 经验上下文

项目记忆语言：简体中文。

在这里记录重复踩坑和已验证修复。

## 条目索引

当目录超过少量条目时，可维护这个人工索引。

| 文件 | 摘要 | 关键词 |
| --- | --- | --- |
| `example-fix.md` | 一句话说明踩坑场景或可复用修复。 | tool, failure-mode |

索引列只用于 public-safe discovery metadata。只有在 `Maturity` 或 `Reviewed` 由人工维护时，
才允许加入这些可选列；不要包含 runtime telemetry、usage counts、`last_accessed`
或 automatic decay state。

每条经验保持简洁：
1. Problem（问题）
2. Root Cause（根因）
3. Fix（修复）
4. Verification（验证）
5. Prevention rule（预防规则）
