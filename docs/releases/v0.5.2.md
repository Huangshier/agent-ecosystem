## 中文

`v0.5.2` 是一个稳定化补丁版本。它打包 `v0.5.1` 之后已经合入 `main` 的公开变更，重点是
Claude Code hooks 生命周期模板、skills metadata / discovery 兼容性、测试和 eval 迭代能力、
知识生命周期 metadata，以及 context index guidance。

### 主要变更

- Claude Code hooks / lifecycle hooks：新增项目模板中的 guardrails contract、`.claude/settings.json`
  生命周期注册，以及 `SessionStart`、`PreToolUse`、`Stop` hook runner；覆盖 Bash、PowerShell
  和 command-based Monitor 风险检查，并用 public-safe fixtures 纳入 release validation。（#205 /
  PR #206 / PR #207）
- Skills metadata / discovery：完成 cross-runtime compatibility audit，新增 additive frontmatter
  `metadata` map、保守 `compatibility` 字段，以及只读 skills discovery command card，帮助 agent
  发现本地 skills 而不自动安装、启用或声明客户端兼容性。（#165 / PR #192 / PR #193 / PR #194 /
  PR #213）
- 测试和 eval 迭代：补充 testing workflow templates、spec testing evidence guidance、testing-core
  domain pack、eval-driven skill iteration pattern、baseline / report / runner-output fixtures、
  deterministic regeneration 和 benchmark contract。（#166 / #168 / #210 / PR #191 / PR #195 /
  PR #196 / PR #197 / PR #198 / PR #199 / PR #200 / PR #201 / PR #208 / PR #209 / PR #212）
- 知识生命周期与 context index：#167 的 public-safe split scope 已由 PR #190、PR #214 和
  PR #215 收尾，覆盖 hot memory soft-length diagnostics、experience lifecycle metadata、
  generated index lifecycle fields、no-op rebuild stability、无 public `last_accessed` writeback、
  以及 project-agent context index guidance。
- 轻量 workflow 改进：补充 workflow-spec-lite requirements clarification、Decision Validation、
  ADR usage guidance、术语表模板 guidance 和 issue-decomposition fixture。（#169 / #183 / #185 /
  #188 / PR #182 / PR #186 / PR #187 / PR #189）

### 验证结果

- 最终本地 release validation 通过：
  `PASS=81 FAIL=0 WARN=0 DEFERRED=0`。
- `v0.5.2` final validation 使用：
  `pwsh -NoProfile -File scripts/validate-release.ps1 -TargetVersion v0.5.2`。
- 同一目标版本也通过 Windows PowerShell 5.1 validation：
  `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/validate-release.ps1 -TargetVersion v0.5.2`。
- Release validator 从 `v0.5.1` 的 62 个 PASS 增长到 81 个 PASS，新增覆盖 hooks guardrails、
  hooks runtime、eval iteration、governance workflow、knowledge lifecycle metadata 和 context
  index guidance。

### 升级 / 使用影响

- 对现有安装者没有强制迁移要求。
- `minimal`、`recommended`、`full`、`dev` profile 行为没有变化。
- 新增 Claude Code hooks 模板属于项目模板可靠性增强；它不是 security sandbox，Claude Code
  host permissions 仍是权限边界。
- Testing-core domain pack 和 eval artifacts 是 knowledge / validation layer 增强，不自动改变
  install profile expansion。
- Experience lifecycle fields 是 human-reviewed public metadata；search/read path 不写 public
  durable usage telemetry。

### 已知限制

- #132 runtime state bridge proposal 仍为长期开放提案，不属于本版本 blocker。
- #156 和 #211 仍为 deferred open issues，不属于本版本范围。
- 本版本不新增 repository settings、rulesets、secrets、runner、tag、release publication automation，
  不添加 Bash / Zsh wrappers，也不改变 install profile behavior。
- Knowledge lifecycle automation 仍保持 public-safe boundary：不做 public `last_accessed` writeback、
  runtime usage telemetry writes、automatic maturity downgrade、automatic decay mutation 或
  user-correction-driven sedimentation。

### 风险 / 回滚

- 风险集中在模板、文档和 validator coverage 增长；用户 runtime 兼容风险较低。
- 如 hooks 模板或 eval fixtures 需要调整，可以通过后续治理 PR 修正模板和验证覆盖。
- 如发布文本需要修正，可以进行 GitHub Release body-only 修订，或通过后续 docs PR 同步 release notes。

## English

`v0.5.2` is a stabilization patch release. It packages public changes already
merged to `main` after `v0.5.1`, focused on Claude Code lifecycle hook
templates, skills metadata and discovery compatibility, testing and eval
iteration support, knowledge lifecycle metadata, and context index guidance.

### Highlights

- Claude Code hooks / lifecycle hooks: added project-template guardrails,
  `.claude/settings.json` lifecycle registration, and a `SessionStart`,
  `PreToolUse`, and `Stop` hook runner; covered Bash, PowerShell, and
  command-based Monitor risk checks with public-safe fixtures in release
  validation. (#205 / PR #206 / PR #207)
- Skills metadata / discovery: completed the cross-runtime compatibility audit,
  added additive frontmatter `metadata` maps, conservative `compatibility`
  fields, and read-only skills discovery command cards so agents can discover
  local skills without installing, enabling, or claiming client compatibility
  automatically. (#165 / PR #192 / PR #193 / PR #194 / PR #213)
- Testing and eval iteration: added testing workflow templates, spec testing
  evidence guidance, a testing-core domain pack, the eval-driven skill
  iteration pattern, baseline / report / runner-output fixtures, deterministic
  regeneration, and a benchmark contract. (#166 / #168 / #210 / PR #191 /
  PR #195 / PR #196 / PR #197 / PR #198 / PR #199 / PR #200 / PR #201 /
  PR #208 / PR #209 / PR #212)
- Knowledge lifecycle and context index: completed the public-safe #167 split
  scope through PR #190, PR #214, and PR #215, covering hot memory soft-length
  diagnostics, experience lifecycle metadata, generated index lifecycle fields,
  no-op rebuild stability, no public `last_accessed` writeback, and
  project-agent context index guidance.
- Lightweight workflow improvements: added workflow-spec-lite requirements
  clarification, Decision Validation, ADR usage guidance, terminology template
  guidance, and an issue-decomposition fixture. (#169 / #183 / #185 / #188 /
  PR #182 / PR #186 / PR #187 / PR #189)

### Validation

- Final local release validation passed:
  `PASS=81 FAIL=0 WARN=0 DEFERRED=0`.
- `v0.5.2` final validation used:
  `pwsh -NoProfile -File scripts/validate-release.ps1 -TargetVersion v0.5.2`.
- The same target version also passes Windows PowerShell 5.1 validation:
  `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/validate-release.ps1 -TargetVersion v0.5.2`.
- Release validation grew from the `v0.5.1` 62-PASS baseline to 81 PASS checks,
  adding coverage for hooks guardrails, hooks runtime, eval iteration,
  governance workflow, knowledge lifecycle metadata, and context index guidance.

### Upgrade / Usage Impact

- Existing installations do not need a forced migration.
- `minimal`, `recommended`, `full`, and `dev` profile behavior is unchanged.
- New Claude Code hooks templates improve project-template reliability; they
  are not a security sandbox, and Claude Code host permissions remain the
  permission boundary.
- The testing-core domain pack and eval artifacts are knowledge / validation
  layer enhancements and do not automatically expand install profiles.
- Experience lifecycle fields are human-reviewed public metadata; search/read
  paths do not write public durable usage telemetry.

### Known Limitations

- #132, the runtime state bridge proposal, remains a long-term open proposal and
  is not a blocker for this release.
- #156 and #211 remain deferred open issues and are out of scope for this
  release.
- This release does not add repository settings, rulesets, secrets, runners,
  tag automation, release publication automation, Bash / Zsh wrappers, or
  install profile behavior changes.
- Knowledge lifecycle automation remains within the public-safe boundary: no
  public `last_accessed` writeback, runtime usage telemetry writes, automatic
  maturity downgrade, automatic decay mutation, or user-correction-driven
  sedimentation.

### Risk / Rollback

- Risk is concentrated in templates, documentation, and validator coverage
  growth; user-runtime compatibility risk is low.
- If hooks templates or eval fixtures need adjustment, maintainers can correct
  the templates and validation coverage through a follow-up governance PR.
- If release text needs correction, maintainers can make a body-only GitHub
  Release edit or synchronize the release notes through a follow-up docs PR.
