# v0.3.0 Release Notes

Status: public release

`v0.3.0` ships the public backlog remediation work after `v0.2.0` and resolves
two public maintenance issues through the standard GitHub issue and pull request
flow.

## Highlights

- Manifest-based uninstall removes only paths recorded in
  `install-manifest.json`, preserves unknown runtime files, and prints manual
  cleanup guidance when the manifest is missing.
- Shared PowerShell helper extraction keeps path guard behavior consistent
  across installer, uninstaller, benchmark, and release validation scripts.
- Release validator modularization keeps common test utilities in
  `scripts/validation/release-test-helper.ps1`.
- The release gate now includes a context gate large context benchmark with 500
  generated context files.
- The public shell strategy documents PowerShell as the canonical script
  surface and defers Bash or Zsh wrappers to a later release.
- Memory diagnosis and upgrade analysis accept localized context discovery
  headings while preserving English-first public templates.
- Bilingual Public/Private Routing is documented as a reusable public knowledge
  standard and linked from the language policy.

## Validation Surface

The release gate covers:

- installer profiles and copy/link runtime modes
- manifest-based uninstall behavior with unknown runtime files preserved
- recommended runtime smoke
- hub lock drift check
- public knowledge catalog and domain-pack catalog entries
- localized context discovery headings for memory diagnosis and upgrade
  analysis
- bilingual public/private routing documentation coverage
- context gate large context benchmark
- spec-lite validator positive and negative fixtures
- anti-drift template coverage
- adoption guide and minimal example coverage
- first-session language write coverage for English and Simplified Chinese
- public sensitive scan, parser checks, JSON parsing, and whitespace checks

Expected local result for the release candidate:

```text
PASS=32 FAIL=0 WARN=0 DEFERRED=0
```

## Public Boundary

This release does not publish private domain skills, private overlay content,
machine-specific paths, local migration mappings, or sensitive audit details.

Private overlay CI visibility work remains private-side follow-up state and is
not a public release blocker.
