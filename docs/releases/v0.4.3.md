# v0.4.3 Release Notes

Status: public release

`v0.4.3` is a post-convergence stabilization release. It stabilizes the public
repository after the `v0.4.1` template-authority consolidation and the
`v0.4.2` language-scoped template convergence, before any `v0.5.0` expansion
work.

## Highlights

- `v0.4.1` and `v0.4.2` release records are normalized across README
  entrypoints, changelog, release readiness, release notes, and release
  validation.
- Legacy template-path references are audited. Active setup guidance points to
  `templates/languages/<language>/project-root|project-agent`, while historical
  references are marked as legacy, removed, superseded, or historical state.
- Existing `.agents` projects have a conservative upgrade guide that preserves
  project-specific memory and runtime-generated context while using an
  analyze -> plan -> backup -> apply -> validate flow.
- Release validation covers the new release records, legacy path audit, upgrade
  path guidance, and the `v0.4.3` release notes.

## Public Boundary

This release does not publish private overlay content, local migration mappings,
machine-specific paths, private review material, or local-only automation
material.

The project remains a Workflow Kernel. This release does not add a real public
domain pack, promote `embedded-core` to a scriptable skill, or change `full` /
`dev` profile behavior.
