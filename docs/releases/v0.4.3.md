# v0.4.3 Release Notes

Status: release prep draft

`v0.4.3` is planned as a post-convergence stabilization release. It prepares
the public repository after the `v0.4.1` template-authority consolidation and
the `v0.4.2` language-scoped template convergence, before any `v0.5.0`
expansion work.

This document is a draft for maintainer review. It is not a published release,
tag, or GitHub Release.

## Highlights

- `v0.4.1` and `v0.4.2` release records are normalized across README
  entrypoints, changelog, release readiness, release notes, and release
  validation.
- Legacy template-path references are audited. Active setup guidance points to
  `templates/languages/<language>/project-root|project-agent`, while historical
  references are marked as legacy, removed, superseded, or historical state.
- Existing `.agents` projects have a conservative upgrade guide that preserves
  project-specific memory and runtime-generated context while using an
  analyze -> plan -> backup -> apply -> validate flow.
- Release validation covers the new release records, legacy path audit, upgrade
  path guidance, and this release-prep note.
