# v0.3.1 Release Notes

Status: public release

`v0.3.1` is a stabilization release for the public Workflow Kernel adoption
surface. It keeps the kernel scope unchanged and focuses on clearer positioning,
release metadata consistency, maintainer review hygiene, and GitHub Actions
runtime maintenance.

## Highlights

- The root README now leads with the Workflow Kernel positioning, extension
  model, and explicit non-goals.
- `README.zh-CN.md` now mirrors the current positioning as a concise localized
  entrypoint.
- Release validation metadata is normalized so the v0.3.0 release notes match
  the current validator summary.
- The release validator now checks the exact v0.3.0 validation summary and
  includes v0.3.1 release notes coverage.
- The release process now includes a lightweight Public Reader Review checklist
  for README, docs entrypoints, release notes, and release process changes.
- The release validation workflow now uses Node 24-compatible action versions:
  `actions/checkout@v6` and `actions/upload-artifact@v7`.

## Validation Surface

The release gate covers:

- installer profiles and copy/link runtime modes
- manifest-based uninstall behavior with unknown runtime files preserved
- recommended runtime smoke
- hub lock drift check
- hub initialization Git mode and no-op experience index rebuild behavior
- public knowledge catalog and domain-pack catalog entries
- localized context discovery headings for memory diagnosis and upgrade
  analysis
- bilingual public/private routing documentation coverage
- context gate large context benchmark
- spec-lite validator positive and negative fixtures
- anti-drift template coverage
- adoption guide and minimal example coverage
- first-session language write coverage for English and Simplified Chinese
- public sensitive scan, parser checks, JSON parsing, and whitespace checks
- v0.2.0, v0.3.0, and v0.3.1 release notes coverage

## Public Boundary

This release does not publish private domain skills, private overlay content,
machine-specific paths, local migration mappings, or sensitive audit details.

The project remains a Workflow Kernel rather than an agent runtime, model
orchestration framework, or universal workflow bundle.
