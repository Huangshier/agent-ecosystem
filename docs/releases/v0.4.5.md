## 中文

`v0.4.5` 是一个维护 / 兼容性 / 治理补丁版本。它打包 `v0.4.4` 之后已经
合入 `main` 的公共变更，重点是 CI 工作流权限加固、issue 模板完善、以及
验证器在中文 spec 文件和并发事件下的兼容性修复。

### 主要变更

- Issue 分类标签同步幂等性：修复并发 `issues` 事件处理，使标签移除
  在标签已不存在时不再失败。（#102 / PR #104）
- Spec 验证器 zh-CN 锚点对齐：使 workflow-spec-lite 验证器正确识别
  简体中文标题锚点。（#94 / PR #105）
- UTF-8 no-BOM 验证器处理：修复 `validate_spec` 对无 BOM 的 UTF-8 文件
  检测失败的问题，避免 zh-CN spec 文件的误报。（#106 / PR #107）
- Release validation 工作流权限：为
  `.github/workflows/release-validation.yml` 添加最小显式 `permissions`
  块（`contents: read`、`actions: write`），使 CI 安全边界明确化。
  （#95 / PR #108）
- 通用 issue 模板：新增 `bug-report.md` 和 `feature-request.md` 模板，
  与现有 `agent-candidate.md` 并存，使非 agent 的 issue 提交更清晰。
  （#99 / PR #109）

## English

`v0.4.5` is a maintenance / compatibility / governance patch release. It
packages public changes already merged to `main` after `v0.4.4`, focused on
CI workflow permission hardening, issue template improvements, and validator
compatibility fixes for zh-CN spec files and concurrent events.

### Highlights

- Issue triage label-sync idempotency: fixed concurrent `issues` event
  handling so label removal no longer fails when a label is already absent.
  (#102 / PR #104)
- Spec validator zh-CN anchors: aligned the workflow-spec-lite validator
  with Simplified Chinese heading anchors so zh-CN spec fixtures validate
  correctly. (#94 / PR #105)
- UTF-8 no-BOM validator handling: fixed `validate_spec` UTF-8 detection
  for files saved without a BOM, preventing false validator failures on
  zh-CN spec files. (#106 / PR #107)
- Release validation workflow permissions: added an explicit minimal
  `permissions` block to `.github/workflows/release-validation.yml`
  (`contents: read`, `actions: write`) to make the CI security boundary
  explicit. (#95 / PR #108)
- General issue templates: added `bug-report.md` and `feature-request.md`
  templates alongside the existing `agent-candidate.md`, making non-agent
  issue intake clearer. (#99 / PR #109)

### Validation

- Pre-publication local release validation passed:
  `PASS=53 FAIL=0 WARN=0 DEFERRED=0`.
- Hosted Release validation passed on PR #110, covering Windows
  PowerShell 5.1, Windows `pwsh`, Ubuntu `pwsh`, and macOS `pwsh`.

### Upgrade / Usage Impact

- Existing installations do not need a forced migration.
- `minimal`, `recommended`, `full`, and `dev` profile behavior is unchanged.
- New issue templates do not affect existing installations or runtime
  behavior.

### Known Limitations

- This release does not address validator modularization (#96), PowerShell
  helper ownership (#97), issue hygiene (#98), or spec completion (#100).
- This release does not add public domain packs, change install profile
  behavior, or modify repository settings, rulesets, or secrets.

### Risk / Rollback

- Risk is concentrated in CI workflow permissions and validator compatibility
  fixes; user-runtime compatibility risk is low.
- If CI workflow permissions need adjustment, the maintainer can modify the
  `permissions` block in `.github/workflows/release-validation.yml`
  directly.
