## 中文

`v0.4.4` 是一个已发布的稳定化 / 文档 / 治理补丁版本。它打包
`v0.4.3` 之后已经合入 `main` 的公共变更，重点是发布记录整理、PR 与
工作流护栏、工程记忆语言治理、中文首页、领域包治理生命周期，以及
双语发布材料。

### 主要变更

- 发布与文档治理：补齐 `v0.4.3` 发布后记录，新增 `v0.4.4` 双语发布说明，
  并整理 `CHANGELOG.md`、release readiness 与 release notes 索引。
- 工作流护栏：加入跨项目 closeout 写入范围保护、跨工作区 root 校验、
  `/goal` source/reference evidence 要求、高风险 evidence gate、PR base
  guard 与 release-validation concurrency。
- 工程记忆语言与迁移：明确 project-bootstrap analyze / refresh / reset 语义，
  增加只读 body-level project-memory language audit helper，并改进
  `en` / `zh-CN` 语言迁移 review flow。
- 公开仓库边界：root `.agents/` 变为本地 runtime memory，不再作为公开事实源；
  `docs/specs/**` 已完成状态审计，避免把短期分支、PR 或托管检查等待状态写入
  长期公开工作包。
- 用户文档：`README.md` 成为简体中文首页，`README.en.md` 保持英文入口；
  domain-pack governance lifecycle 已记录，但没有启用新的 public domain pack。

## English

`v0.4.4` is a published stabilization / docs / governance patch release. It
packages public changes already merged to `main` after `v0.4.3`, focused on
release-record hygiene, PR and workflow guardrails, project-memory language
governance, the Simplified Chinese homepage, domain-pack governance lifecycle,
and bilingual release material.

### Highlights

- Release and documentation governance: reconciled post-publication `v0.4.3`
  records, added this bilingual `v0.4.4` release note, and aligned
  `CHANGELOG.md`, release readiness, and the release notes index.
- Workflow guardrails: added cross-project closeout write-scope protection,
  cross-workspace root verification, `/goal` source/reference evidence
  requirements, a high-risk evidence gate, PR base guard, and
  release-validation concurrency.
- Project-memory language and migration: clarified project-bootstrap analyze /
  refresh / reset semantics, added a read-only body-level project-memory
  language audit helper, and improved the `en` / `zh-CN` migration review flow.
- Public repository boundary: root `.agents/` is checkout-local runtime memory
  rather than a public fact source; completed `docs/specs/**` work-package state
  was reconciled so durable specs do not carry short-lived branch, PR, or
  hosted-check wait state.
- User documentation: `README.md` is now the Simplified Chinese homepage while
  `README.en.md` remains the English entrypoint; the domain-pack governance
  lifecycle is documented without enabling new public domain packs.

### Validation

- Pre-publication local release validation passed:
  `PASS=51 FAIL=0 WARN=0 DEFERRED=0`.
- Final hosted Release validation passed on tag target
  `71fabb372a4cbc024f07c920a0c17b903a77afc2` in run `26269908157`, covering
  Windows PowerShell 5.1, Windows `pwsh`, Ubuntu `pwsh`, and macOS `pwsh`.
- Published GitHub Release:
  https://github.com/Huangshier/agent-ecosystem/releases/tag/v0.4.4

### Upgrade / Usage Impact

- Existing installations do not need a forced migration.
- `minimal`, `recommended`, `full`, and `dev` profile behavior is unchanged;
  `full` and `dev` remain reserved future public scopes and currently install
  the same public content as `recommended`.
- Existing `.agents` projects can keep using the conservative analyze -> plan ->
  backup -> apply -> validate flow. The new audit helper is read-only; it does
  not translate or rewrite project memory automatically.

### Known Limitations

- Issue #23 remains the deferred next-version release-planning reference. This
  release does not implement it, reopen it, or select domain-pack expansion.
- This release does not add public domain packs, change install profile
  behavior, ship Bash / Zsh wrappers, or modify repository settings, rulesets,
  or secrets.

### Risk / Rollback

- Risk is concentrated in documentation, governance, and validation coverage;
  user-runtime compatibility risk is low.
- Release artifacts already exist. Any tag or GitHub Release adjustment must be
  separately authorized by the maintainer through the release process; these
  notes do not authorize moving tags, republishing releases, or direct `main`
  changes.
