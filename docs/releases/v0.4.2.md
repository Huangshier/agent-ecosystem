# v0.4.2 Release Notes

Status: public release

`v0.4.2` converges the template layout introduced in `v0.4.1` into one
language-scoped model. Project-root and project-agent templates now share the
same `templates/languages/<language>/...` hierarchy in the public knowledge hub
and in the bundled `project-bootstrap` snapshot.

Historical note: references below to top-level `templates/project-root`,
`templates/project-agent`, and `templates/project-memory` describe legacy
directories removed by this release, not supported current entrypoints.

## Highlights

- Public templates now use
  `knowledge-hub/templates/languages/en|zh-CN/project-root|project-agent/**`.
- The bundled snapshot now uses
  `skills/project-bootstrap/assets/knowledge-hub-template/templates/languages/en|zh-CN/project-root|project-agent/**`.
- Legacy top-level `templates/project-root`, `templates/project-agent`, and
  `templates/project-memory` entry trees were removed.
- Plain bootstrap now defaults to English language templates.
- Bootstrap, language migration, hub initialization, hub-lock checks, docs, and
  release validation were updated for the converged layout.
- The release keeps `minimal`, `recommended`, `full`, and `dev` profile
  behavior unchanged.

## Public Boundary

This release does not publish private overlay content, local migration mappings,
machine-specific paths, private review material, or local-only automation
material.

The project remains a Workflow Kernel. `full` and `dev` profiles stay reserved
for future public expansion work after the kernel base flow is stable.
