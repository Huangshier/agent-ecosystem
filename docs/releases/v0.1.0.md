# Agent Ecosystem v0.1.0

Initial public Workflow Kernel release.

## Included

- `project-bootstrap`
- `project-context-gate`
- `workflow-spec-lite`
- `memory-governance`
- public knowledge hub templates
- installer support for `minimal`, `recommended`, `full`, and `dev` profile
  names

## Notes

- `full` and `dev` were reserved profile names in this release and installed
  the same public content as `recommended`.
- Domain-specific skills and private overlay content were intentionally kept
  outside the public release.
