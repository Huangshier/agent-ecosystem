# v0.2.0 Release Notes

Status: public release

`v0.2.0` closes the public migration work for the Workflow Kernel and prepares
the project for normal maintenance after migration.

## Highlights

- First-session project memory language write support through explicit
  `project-bootstrap -ProjectLanguage` input.
- Release validator now reports zero deferred checks for the v0.2.0 gate.
- `workflow-spec-lite` includes a read-only spec completeness validator.
- Scope drift, unrelated refactor, and skipped acceptance protections are
  present in templates and memory-governance guidance.
- Public knowledge hub includes a catalog-first domain-pack scaffold for
  `embedded-core`.
- Public adoption guide and minimal project example show how to adapt the
  Workflow Kernel without a private overlay.

## Validation Surface

The release gate covers:

- installer profiles and copy/link runtime modes
- recommended runtime smoke
- hub lock drift check
- public knowledge catalog and domain-pack catalog entries
- spec-lite validator positive and negative fixtures
- anti-drift template coverage
- adoption guide and minimal example coverage
- first-session language write coverage for English and Simplified Chinese
- public sensitive scan, parser checks, JSON parsing, and whitespace checks
