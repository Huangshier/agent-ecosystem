# v0.4.1 Release Notes

Status: public release

`v0.4.1` consolidates project-memory template authority after the `v0.4.0`
language migration release. The release moves the public template source to the
knowledge hub, keeps the bundled `project-bootstrap` snapshot aligned, and
removes the standalone skill-local template tree.

## Highlights

- Project-memory templates now live under
  `knowledge-hub/templates/project-memory/en|zh-CN/**`.
- The bundled snapshot under
  `skills/project-bootstrap/assets/knowledge-hub-template/templates/project-memory/en|zh-CN/**`
  matches the public template authority.
- The legacy standalone `skills/project-bootstrap/templates/project-memory/`
  tree was removed.
- Language helper scripts and release validation were updated for the
  authority/snapshot model.
- The release keeps `minimal`, `recommended`, `full`, and `dev` profile
  behavior unchanged.

## Public Boundary

This release does not publish private overlay content, local migration mappings,
machine-specific paths, private review material, or local-only automation
material.

The project remains a Workflow Kernel. `full` and `dev` profiles stay reserved
for future public expansion work after the kernel base flow is stable.
