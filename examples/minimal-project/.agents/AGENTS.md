# Project Agent Guide

## Project Language Policy

Project memory language: English.

Keep project engineering memory in English by default. Keep file names,
commands, paths, API names, and raw error text in English or in their original
form.

## Working Rules

- Confirm goals, non-goals, and acceptance evidence for non-trivial work.
- Do not include unrelated refactors unless they are explicit goals.
- Record skipped validation before claiming completion.
- Keep durable work packages in `docs/specs/`, not in chat history.
